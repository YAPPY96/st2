# Study Tracker 2 Plugin for Blinko

This plugin allows you to check today's study tasks and progress from study-tracker2 directly in Blinko.

## Features

- View today's overall study progress
- See progress for each subject
- Quick access to study-tracker2 statistics

## Setup

1. Make sure study-tracker2 is running (default: http://localhost:8000)
2. Load this plugin in Blinko
3. The plugin will automatically connect to study-tracker2

## Configuration

The default base URL is `http://localhost:8000`. You can change it by clicking the plugin icon in Blinko's toolbar.

## Requirements

- study-tracker2 backend running
- CORS enabled (already enabled in study-tracker2)

## Installation

1. Copy `study-plugin.js` to your Blinko plugins directory
2. Restart Blinko
3. The plugin icon will appear in the toolbar
